# OBSIDIA website and identity

Upload index.html, style.css, script.js and the assets folder into your Hostinger public_html directory. Keep the assets folder structure intact. No build process is needed.

Open brand-guide.html to view the identity, colour palette, typography and usage rules. It does not need to be public.

## Preserved from your website

Services, prices (15 JOD one-time starting price; 19 JOD Personal Care; 89 JOD Business Care), offers, phone number and email remain unchanged. Confirm these commercial details before launch.

WhatsApp links open the existing number without a prewritten message.

The canonical URL and structured-data URL still point to your existing https://0m8rn.github.io/losios/ address. That is intentionally preserved, not a missed rebrand: replace both with your real domain when it is chosen. No unowned OBSIDIA domain or email was invented.

## Identity files

- assets/obsidia-logo.svg: gold symbol and chalk wordmark, transparent.
- assets/obsidia-logo-dark.svg: black version for light surfaces.
- assets/obsidia-logo-white.svg: white version for dark surfaces.
- Matching logo PNGs are transparent and 2000 px wide.
- assets/obsidia-symbol.svg: gold standalone vector symbol.
- assets/obsidia-symbol-light.svg and obsidia-symbol-dark.svg: single-colour symbols.
- assets/obsidia-avatar.png: 1080 × 1080 profile image with black background.
- assets/obsidia-favicon.svg: browser icon.
- assets/obsidia-favicon.png: 180 × 180 touch icon.

Logos are vector paths, not font-dependent text. Website fonts load from Google Fonts with system fallbacks.

No hosting account, DNS, domain purchase or existing live deployment was changed. Brand artwork is not legal clearance for the name.
